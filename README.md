# Student Management System

A Student Management System built with Laravel 12 that provides complete student management with CRUD operations, search, filtering, sorting, pagination, dashboard statistics, and CSV export.

## Features

- Create Student
- Update Student
- Delete Student
- Search Students
- Filter by Status
- Sort by Student Number
- Pagination
- Dashboard Statistics
- Export CSV

## Technologies

- Laravel 12
- PHP 8
- MySQL
- Bootstrap 5
- Blade
- Git
- GitHub

## Installation

```bash
git clone https://github.com/ibtisam5/student-management.git

cd student-management

composer install

cp .env.example .env

php artisan key:generate

php artisan migrate

php artisan serve
```
